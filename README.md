# Цифровой гербарий Приморского края

Веб-проект, посвященный растениям Приморского края, оформленный как винтажный ботанический полевой журнал. Сайт объединяет атмосферу старинного гербария, исследовательскую эстетику и современную цифровую подачу, превращая коллекцию образцов в живую визуальную историю о природе Дальнего Востока.

## О проекте

**Цифровой гербарий Приморского края** — это статический адаптивный веб-сайт, в котором ботаническая коллекция представлена в формате уютного архивного альбома. Интерфейс вдохновлен страницами полевого дневника: состаренная бумага, рукописные акценты, карточки образцов, декоративные печати и визуальные детали создают ощущение настоящей исследовательской коллекции.

Проект показывает, как можно соединить образовательный контент, региональную природную тематику и художественную веб-подачу в одном цельном цифровом пространстве.

## Особенности

- Винтажный визуальный стиль в духе ботанического журнала и гербарного архива
- Адаптивная верстка для desktop, tablet и mobile
- Каталог растений с карточками образцов
- Поиск по названиям растений и латинским наименованиям
- Фильтрация по категориям
- Модальное окно с подробной информацией о каждом образце
- Декоративные элементы: бумажные ярлыки, сургучные печати, заметки, текстуры и архивные детали

## Тематика коллекции

В проекте представлены растения, связанные с флорой Приморского края, включая цветы, деревья, травы и папоротники. Каждая карточка сопровождается названием, латинским обозначением, датой, местом сбора, описанием среды произрастания и дополнительными ботаническими сведениями.

## Технологии

- CSS3
- JavaScript (Vanilla JS)
- Google Fonts для типографики и визуального образа

## Запуск проекта

Для корректной работы проект лучше открывать через локальный сервер.

Пример:

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000
```

## Идея и художественный образ

Этот проект задуман не просто как каталог растений, а как цифровое пространство памяти о природе родного края. Он передает ощущение внимательного наблюдения, бережного изучения и уважения к природному наследию Приморья. Через визуальный язык старинного гербария сайт делает ботанику ближе, теплее и эмоциональнее.
